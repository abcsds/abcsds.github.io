# Proyectos de Código Abierto

- [**Psychopy-NixOS**](https://github.com/abcsds/Psychopy-NixOS) — Lanzador de PsychoPy gestionado con Nix, confiable, para cualquier host NixOS.
- [**DFA.jl**](https://github.com/abcsds/DFA.jl) — Detrended Fluctuation Analysis (Análisis de Fluctuación sin Tendencia): un paquete de Julia para el análisis de correlaciones de largo alcance en series temporales.
- [**HRBand-LSL**](https://github.com/abcsds/HRBand-LSL) — Una herramienta de adquisición de bioseñales de alta precisión para datos de frecuencia cardíaca utilizando Lab Streaming Layer.
- [**VizHRV**](https://github.com/abcsds/VizHRV) — Una herramienta de visualización de bioseñales para datos de frecuencia cardíaca utilizando Makie.jl y Lab Streaming Layer.
- [**DDMViz**](https://github.com/abcsds/DDMViz) — Una herramienta de visualización para el Drift Diffusion Model (Modelo de Difusión de Deriva).
- [**NBack**](https://github.com/abcsds/Nback) — Una tarea cognitiva para la evaluación de la memoria de trabajo.
- [**ANT**](https://github.com/abcsds/ANT) — Attention Network Test (Prueba de Redes Atencionales): una tarea cognitiva para la evaluación de las redes atencionales.
- [**DualTask**](https://github.com/abcsds/DualTask) — Una tarea cognitiva para la evaluación de la atención dividida.
- [**RDM**](https://github.com/abcsds/RDM) — Random Dot Motion Task (Tarea de Movimiento de Puntos Aleatorios): una tarea cognitiva para la evaluación de la toma de decisiones perceptual.
- [**FFMQ**](https://github.com/abcsds/FFMQ) — Una tarea cognitiva para la evaluación digital del mindfulness utilizando el Five Facet Mindfulness Questionnaire (Cuestionario de las Cinco Facetas del Mindfulness).
- [**FaceOddball**](https://github.com/abcsds/FaceOddball) — Una tarea cognitiva de tipo oddball que utiliza rostros como estímulos objetivo.
